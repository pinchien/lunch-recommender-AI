今天中午吃什麼？

依地址、餐點種類、預算與身體狀態，綜合距離及 Google 評分推薦 5 家餐廳。

輸入地址時會顯示 Google 地址建議，請直接點選建議地址，可降低地址解析失敗。
此版本支援 Google Maps Demo Key，並使用 Places API (New) 的 Place.searchNearby。Demo Key 僅適合測試與原型；正式上線請改用正式 API Key。
注意：Demo Key 無法取得 Google 使用者原創內容，例如評論；Google 評分等欄位若未回傳，推薦會主要依距離等可取得資料排序。

健康狀態只用於調整搜尋關鍵字，不是醫療建議。價格為 Google 的價位等級估算，請以店家現場資訊為準。
